# 交付前检查清单

复制到一期的工作目录，逐项打勾；没有打勾的写进交付报告。

## 拆片

- [ ] `probe.json`、联系表、镜头切点、字幕 OCR/人工读、配乐 BPM/重拍都齐了
- [ ] 拆解报告写了：镜头表、主色/强调色、字体层级、入场/转场、配乐重拍
- [ ] 写清「不搬的东西」：原片句子、标题、水印、创作者、具体帧

## 文案

- [ ] 锚词 2–4 字，开头出现、第二高潮砸出、结尾重新定义
- [ ] 冷开场 4 个日常悖论，一拍一个
- [ ] 中文每句 ≤18 字；英文不为空
- [ ] 结尾以「？」收
- [ ] 每个数字/年份/人名有一手来源；示意图标「示意」

## 时间表

- [ ] `BAR/BAR0` 用实测重拍反推
- [ ] `HIT` / `HIT2` 离实测重拍 ≤2 帧
- [ ] `DARK_FROM` 在重拍前约 0.75 秒；`FREEZE=3`
- [ ] `CUES` 全部卡小节线；`SHOTS` 首尾相接覆盖全片
- [ ] `SFX` 有重拍冲击、关键数字、转场
- [ ] 测试覆盖：重拍、字幕、锚词、结尾问号、镜头连续、数字常量

## 画面

- [ ] 全片是 2D；没有 `three` / `@react-three/*`
- [ ] 动画全是帧号纯函数；没有 `Math.random()` / CSS 动画 / 真实时间
- [ ] 有一条贯穿母题
- [ ] 每个镜头抽帧看过：字不重叠/不出画、该出现的出现了
- [ ] 两个高潮前后 6 帧：收暗 → 静止 3 帧 → 爆发
- [ ] 没有原片帧、水印、创作者名字

## 声音

- [ ] 配乐有来源/授权说明；抽参考音轨的已标红
- [ ] 音效不抢配乐
- [ ] 整片 −16 LUFS 左右，峰值 ≤ −1.5 dBFS
